Install from a terminal

Linux and macOS:

curl -fsSL https://YOUR-KEENU-DOMAIN/install.sh | sh

Windows PowerShell:

irm https://YOUR-KEENU-DOMAIN/install.ps1 | iex

To read a script before running it, which is a good idea with any script from the internet:

curl -fsSLO https://YOUR-KEENU-DOMAIN/install.sh
less install.sh
sh install.sh

Each checks its download against the published SHA-256 before installing, and needs no development tools.

On Linux, Keenu is a GNOME Shell extension and needs GNOME Shell 46 to 51. See the source code for what works on each system.
