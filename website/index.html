Download for your system

Or install and start it with one command

Linux and macOS, in a terminal:

curl -fsSL https://raw.githubusercontent.com/groot-code24/keenu/main/scripts/install/install.sh | sh

Windows, in PowerShell:

irm https://raw.githubusercontent.com/groot-code24/keenu/main/scripts/install/install.ps1 | iex

Each checks its download against the published SHA-256 before installing, installs for your user only, and needs no development tools.

Before you install

This is an alpha. What works where says what has and has not been tested on each system.

Windows: the installers are not code signed yet, so if you download one, SmartScreen may say it is from an unknown publisher.

macOS: the app is not notarized by Apple yet. If macOS refuses to open a download, allow it in System Settings > Privacy & Security.

Linux: Keenu is a GNOME Shell extension and needs GNOME Shell 46 to 51. Log out and back in once after installing, so GNOME Shell loads it.
